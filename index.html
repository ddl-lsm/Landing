FAQ

Common questions

Do you work remotely or on-site?

Both. Smart home configuration and app development are done remotely. Hardware installation requires on-site work — available with travel arrangements included.

Can you integrate my existing devices?

In most cases, yes. Home Assistant supports Xiaomi, Tuya, Aqara, Sonoff, Shelly, Legrand, ABB, Philips Hue and hundreds more. I'll confirm compatibility before we start — free of charge.

How fast can you deliver an MVP app?

A focused mobile MVP typically takes 4–6 weeks. A smart home dashboard app can be ready in 2–3 weeks if Home Assistant is already set up.

What's the minimum budget for a smart home project?

Configuration and automation work starts from $500. Full-cycle projects (hardware + HA + custom app) start from $1,200 depending on device count and complexity.

Do you offer ongoing support?

Yes. Monthly retainer plans are available for monitoring, updates and new features. All projects include 30 days of free post-launch support.
