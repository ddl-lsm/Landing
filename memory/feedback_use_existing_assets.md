---
name: Feedback — использовать готовые файлы логотипа
description: Не пересоздавать логотип в SVG когда есть готовые PNG/WebP файлы
type: feedback
---

Не пересоздавать логотип в SVG из головы, когда пользователь предоставил готовые файлы (PNG, WebP).
Использовать существующие файлы напрямую через тег img.

**Why:** Попытка "улучшить" логотип своими силами без запроса пользователя — грубая ошибка.
Пользователь сам создал логотип и он им доволен. Задача — только использовать его, не переделывать.

**How to apply:** При наличии готовых файлов логотипа в проекте (LOGO/, assets/ и т.п.) —
всегда использовать их напрямую. SVG-реконструкция допустима только если пользователь
явно просит воссоздать логотип в векторном формате.
